# MARS Rover Earth Ground Station

这是面向真实 ROS2 小车的局域网监督平台。平台自动发现同一局域网中的小车，操作员选择连接后，可以查看运行状态、地图与路径、目标感知、任务进度和系统诊断。

本仓库只包含监督平台和平台接入网关，不包含小车端导航、识别、探索、避障或底盘代码。

## 一步启动

```bash
./START_MARS_ROVER.py
```

只使用这一个入口。它会读取 `config/team_config.json`、启动 Web 服务、检查局域网端口，并在电脑已安装 ROS2 Humble 时自动启动 DDS 网关。启动完成后会打开浏览器，并在终端打印可用的平台访问地址。

局域网中的其他电脑打开：

```text
http://平台电脑IP:8080
```

平台仅提供电脑端布局，建议浏览器窗口宽度不低于 1180 像素。

## 连接小车

进入“设备连接”页后，平台会像 Wi-Fi 列表一样显示同一局域网中的小车：

- UDP `38765`：设备多播与广播发现。
- TCP `38766`：选择小车后的连接握手。
- TCP `8080`：平台页面、遥测、地图、相机和任务指令。

点击“连接”时，平台会校验小车网关、`team_id` 和平台健康状态，然后自动设置数据回传地址。连续 7 秒没有心跳的设备会标记为离线，控制按钮会自动禁用。

小车与网关必须使用相同的 `ROS_DOMAIN_ID`，并持续发布 `/team/<team_id>/fleet_state`。默认业务标识 `team-a` 在 ROS2 话题中规范化为 `team_a`。

## 页面

- **设备连接**：发现、选择和连接小车。
- **运行总览**：任务、速度、电量、位置和里程。
- **地图导航**：占据栅格、实际轨迹、规划路径和识别目标。
- **目标感知**：相机画面、目标类别、置信度和坐标。
- **任务控制**：寻找目标、暂停、继续、返航和紧急停车。
- **系统诊断**：传感器、网络、遥测延迟和安全状态。

地图支持二维和立体视图。立体视图是二维 SLAM 占据栅格的立体化表达，不是 OctoMap 或三维点云地图。

## 配置

所有运行配置集中在 `config/team_config.json`：

```json
{
  "team_id": "team-a",
  "stale_after_s": 3.0,
  "device_stale_after_s": 7.0,
  "ros_domain_id": 21,
  "discovery_port": 38765,
  "agent_port": 38766,
  "listen_host": "0.0.0.0",
  "port": 8080
}
```

平台用于受信任的独立小车局域网，不应把控制端口映射到公网。

ROS2 消息格式和接入要求见 [docs/ROS2_INTERFACE.md](docs/ROS2_INTERFACE.md)，系统边界见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

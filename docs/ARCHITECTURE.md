# Architecture

## 1. 定位

本系统是“地球端”人在环监督站。比赛中的信息可见性由物理传感器和己方通信决定，而不是由软件隐藏一个内部全局真值。

## 2. Trust boundary

Ground Station 可接收：

1. 己方 Rover 自身状态。
2. 己方 Rover 发现的物资。
3. 己方 Rover 任务/安全事件。

Ground Station 不定义、也不提供：

1. 敌方车辆状态。
2. 未发现物资位置。
3. 仿真世界状态。
4. 裁判全局真值。

## 3. 人在环边界

监督页面允许操作员发送 `SEARCH_TARGET / HOLD / RESUME / RETURN / EMERGENCY_STOP` 高层意图。

这些消息只进入实体车自主系统的任务层。平台不连续发送速度控制量，不替代本车规划器和安全控制器。

## 4. 局域网设备发现

ROS2 网关从 `/team/<team_id>/fleet_state` 识别真实小车后，每 2 秒向 UDP `38765` 发送一条 `hitl-rover-discovery-v1` 心跳。心跳同时发往局域网多播组 `239.255.73.84`、广播地址和本机回环地址。

Web 后端接收同一 `team_id` 的心跳并维护设备在线状态。连续 7 秒未收到心跳时设备显示为离线；收到真实遥测也会登记设备，避免受限网络阻断多播或广播后完全无法连接。操作员只能连接在线设备，断线后任务按钮自动禁用。

## 5. 页面结构

控制台分为设备连接、运行总览、地图导航、目标感知、任务控制和系统诊断六页。小车连接选择保存在浏览器和平台会话中，地图、相机与控制始终指向当前选择的小车。
